# Jay Joshi — Developer Portfolio

A responsive personal portfolio built with HTML, CSS, and vanilla JavaScript. It uses a dark navy and blue theme and requires no build tools or paid hosting.

## Run locally
1. Extract this ZIP.
2. Keep `index.html`, `style.css`, and `script.js` together in the same folder.
3. Open `index.html` in a browser. VS Code Live Server is optional.

## Publish free with GitHub Pages
1. Create a repository, for example `jay-joshi-portfolio`.
2. Upload `index.html`, `style.css`, and `script.js` to the repository root (you may also upload this README).
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select branch `main` and folder `/ (root)`, then save.
6. Wait for GitHub Pages to publish and use the URL shown in Pages settings.
